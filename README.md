# TypeFlow 🎀 — Hello Kitty Edition Touch Typing Tutor

A complete, modern, interactive typing tutor web application with an adorable **Hello Kitty Kawaii Pink & White mode**, **310 structured lessons across 8 stages**, multi-mode switching (Kawaii / Modern / Dark), and accuracy-first muscle memory conditioning.

## 🎯 Accuracy-First Learning Logic

$$\text{Gross WPM} = \frac{\text{Total Characters Typed} / 5}{\text{Elapsed Minutes}}$$
$$\text{Net WPM} = \max\left(0, \text{Gross WPM} - \frac{\text{Unfixed Errors}}{\text{Elapsed Minutes}}\right)$$
$$\text{Accuracy} = \frac{\text{Correct Keystrokes}}{\text{Total Keystrokes}} \times 100$$

- **95%+ Milestone Requirement**: Promotes accuracy and muscle memory before pushing raw speed.
- **Finger Mistake Diagnostics Heatmap**: Tracks error rate for each of the 10 finger zones to deliver tailored improvement tips.
